# Lockdown

## Overview
Welcome to the Lockdown project. This document serves as the central hub for project documentation, detailing the asset structure, game scripts, and technical components.

## Project Structure (`Lockdown/Assets/Assets`)

The core project content is organized within `Lockdown/Assets/Assets`:

### 1. Scripts
Located in `Scripts/`, these control the core gameplay and systems.

#### Core Gameplay
*   **`Backpack.cs`**: Manages the player's inventory, weapon switching, and interactions.
*   **`Weapon.cs`**: Handles shooting, reloading, zooming, and weapon stats.

#### Systems & Managers
*   **`LevelManager.cs`**: Manages scene transitions (`Menu`, `WarmUp`, `Campaign`).
*   **`PoolManager.cs`**: Optimizes performance by pooling bullets, particles, and enemies.

#### Enemies
*   **`Enemy.cs`**: Base class for enemy AI.
*   **`FixedEnemy.cs`**: Stationary enemies (turrets).
*   **`MovingEnemy.cs`**: Patrolling or chasing enemies.
*   **`EnemyHealth.cs`**: Manages enemy health and death.

#### Items
*   **`Pickup.cs`**, **`AmmoPickup.cs`**, **`WeaponPickup.cs`**: Logic for interactive items.

### 2. Scenes
Located in `Scenes/`:
*   **`Menu`**: The main menu scene.
*   **`WarmUp`**: A training or warm-up level.
*   **`MainLevel`**: The primary campaign gameplay scene.

### 3. Prefabs
Located in `Prefabs/`:
*   **System Prefabs**: `LevelManager`, `Config`.
*   **`Active Weapon`**: Prefabs for weapons equipped by the player.
*   **`Enemies`**: Prefabs for different enemy types.
*   **`Pickup`**: Prefabs for items that can be picked up (ammo, weapons).
*   **`Particles`**: Visual effects for hits, explosions, etc.
*   **`Canvas`**: UI elements.

### 4. ScriptableObjects
Located in `ScriptableObject/`:
*   Contains weapon configuration assets (e.g., `Default Pistol.asset`, `Default Rifle.asset`).
*   These define stats like damage, fire rate, and magazine size for each weapon type.

### 5. 3rd Party Assets
Located in `3d Party Assets/`, this folder contains external resources used in the project:
*   **Audio**: Sound effects and music.
*   **Models & Props**: `Barrel`, `DefenceLazer`, `Gun Sci-fi`, `LP_SciFiWeapons_Lite`.
*   **Characters**: `BattleRoyaleDuoPAPBR`, `Sharp Shooter Assets`.
*   **VFX**: `SimpleFX`.
*   **System**: `StarterAssets` (Unity's starter content).
